# 贪吃蛇游戏

一个使用 Python 和 turtle 库开发的经典贪吃蛇小游戏，支持键盘和鼠标两种操作方式。

## 游戏简介和功能特点

### 游戏简介
贪吃蛇是一款经典的街机游戏，玩家控制一条蛇在游戏区域内移动，通过吃食物来增长身体并获得分数。当蛇头撞到墙壁或自己的身体时游戏结束。

### 功能特点
- 🐍 流畅的蛇移动控制
- 🍎 随机生成食物（圆形红色，距边界4格）
- 📊 实时分数显示
- 🎮 **游戏启动交互**：按 Enter 或 空格键 开始游戏（无延迟，立即开始）
- ⏸️ **暂停功能**：按 P 键暂停/继续游戏
- 🔄 **重新开始功能**：按 R 键随时重新开始
- 🖱️ **鼠标操作**：支持点击按钮开始/暂停/重新开始
- 🎯 **失败判定机制**：
  - 头部碰墙判定
  - 头尾相触判定
- 📝 **失败信息显示**：明确显示失败原因
- 🌈 **隐藏玩法**：蛇会根据分数变色（无提示，需要玩家自己发现）
- ⚡ **难度递增**：随分数增加，蛇会变色并加速

## 游戏操作指南

### 键盘控制
| 按键 | 功能 |
|------|------|
| Enter / 空格键 | 开始游戏 |
| ↑ | 向上移动 |
| ↓ | 向下移动 |
| ← | 向左移动 |
| → | 向右移动 |
| P / 数字1 | 暂停/继续游戏 |
| R / 数字2 | 重新开始游戏 |

### 鼠标操作
在游戏界面右侧有三个按钮：
| 按钮 | 颜色 | 功能 |
|------|------|------|
| 开始游戏 | 🟢 绿色 | 开始游戏 |
| 暂停 | 🟡 橙色 | 暂停/继续游戏 |
| 重新开始 | 🔴 红色 | 重新开始游戏 |

### 游戏规则
1. 游戏启动后，需要按 Enter 或 空格键 开始游戏（无延迟，立即开始）
2. 控制蛇吃到红色食物来获得分数
3. 每吃到一个食物，蛇身会增长一节，分数增加 **10 分**
4. **头部碰墙**：当蛇头撞到游戏边界时，游戏失败
5. **头尾相触**：当蛇头撞到自己的身体时，游戏失败
6. 游戏结束后，按 R 键或点击按钮可以重新开始

### 🌈 隐藏玩法（蛇变色系统）
蛇会根据玩家的分数自动变色，无需任何操作。这是一个隐藏的彩蛋，需要玩家自己发现！

| 分数 | 颜色 | 速度 |
|------|------|------|
| 0-19 | ⚪ 白色 | 1.0x |
| 20-49 | 🟢 绿色 | 1.1x |
| 50-89 | 🔵 蓝色 | 1.2x |
| 90-139 | 🟣 紫色 | 1.3x |
| 140-199 | 🟡 金色 | 1.4x |
| 200-299 | 🔴 红色 | 1.5x |
| 300+ | 🌈 彩虹渐变 | 1.6x |

**注意**：每达到一个颜色分段，速度会增加 0.1 倍，蛇也会变成对应的颜色。这是隐藏玩法，游戏不会有任何提示！

### 核心类说明

#### 1. Snake 类
负责管理蛇的行为和状态：
- `__init__(screen)` - 初始化蛇的位置和绘制对象
- `reset()` - 重置蛇的状态
- `create_turtles()` - 创建蛇的海龟绘制对象
- `update_color(head_color, body_color)` - 更新蛇的颜色
- `update_direction(new_direction)` - 更新移动方向（防止180度转向）
- `move()` - 移动蛇（不穿墙）
- `grow()` - 蛇增长
- `draw()` - 绘制蛇
- `check_self_collision()` - 检查头尾相触
- `check_wall_collision()` - 检查头部碰墙
- `clear()` - 清除蛇的海龟对象

#### 2. Food 类
负责管理食物的生成和绘制：
- `__init__(screen)` - 初始化食物位置和绘制对象
- `generate_new()` - 生成新食物位置（距边界4格）
- `draw()` - 绘制食物
- `clear()` - 清除食物海龟

#### 3. Game 类
游戏主控制器：
- `__init__()` - 初始化游戏环境和界面
- `create_buttons()` - 创建鼠标点击按钮
- `start_game()` - 开始游戏（无倒计时）
- `go_up/go_down/go_left/go_right()` - 方向键处理
- `toggle_pause()` - 暂停/继续（P键）
- `update_score_display()` - 更新分数显示
- `show_start_message()` - 显示开始提示
- `show_status(message)` - 显示游戏状态信息
- `show_fail_reason(reason)` - 显示失败原因
- `check_collisions()` - 碰撞检测（碰墙+头尾相触）
- `update_snake_color()` - 更新蛇的颜色（隐藏玩法）
- `update_rainbow_color()` - 更新彩虹颜色
- `update()` - 更新游戏状态
- `draw()` - 绘制游戏画面
- `reset_game()` - 重置游戏
- `run()` - 游戏主循环

## 核心算法和实现思路

### 1. 游戏状态机
- **waiting_for_start**：等待用户开始
- **playing**：游戏进行中
- **paused**：游戏暂停
- **game_over**：游戏失败

### 2. 蛇的移动算法
- 使用列表存储蛇的身体坐标
- 每次移动时，在列表头部添加新位置，尾部移除一个元素
- 方向控制使用方向向量：UP=(0,1), DOWN=(0,-1), LEFT=(-1,0), RIGHT=(1,0)

### 3. 碰撞检测
- **食物碰撞**：比较蛇头坐标与食物坐标是否相同
- **自身碰撞（头尾相触）**：检查蛇头是否存在于身体列表中
- **碰墙检测**：检查蛇头坐标是否超出游戏边界（提前检测）

### 4. 变色系统（隐藏玩法）
- 根据分数判断当前处于哪个颜色分段
- 分数达到分段阈值时触发变色
- 300分以上进入彩虹模式，颜色周期性变化

### 5. 速度递增系统
- 每个颜色分段速度增加 0.1 倍
- 最高速度限制在 2.5 倍
- 达到彩虹模式后速度上限为 1.6 倍

### 6. 事件驱动机制
- 使用 turtle 的事件绑定处理键盘输入
- Enter/空格键触发游戏开始
- 方向键控制蛇的移动方向
- P键切换暂停状态
- R键触发游戏重置
- 支持数字键 1/2 作为中文输入法下的备用按键
- 使用 tkinter 按钮实现鼠标点击功能

### 7. 游戏循环
```
等待开始 → 游戏进行 → 暂停/继续 → 游戏结束
```
